# DevOps - Tecmilenio

Repositorio de programas y ejercicios desarrollados durante la materia de DevOps en Tecmilenio.
El contenido está organizado por semanas y refleja los temas vistos en clase, como automatización,
integración continua y buenas prácticas de desarrollo. El objetivo es familiarizarse con las
herramientas y metodologías utilizadas en entornos de desarrollo profesional modernos.
